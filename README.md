# ماركتنگ — Factory Market

**برنامج الكاشير لسطح المكتب، يعمل بدون إنترنت.**
**The offline desktop till. Works with no internet.**

هذا المستودع يحتوي على ملف التثبيت فقط. لا يوجد فيه أي شيفرة برمجية.
This repository holds the installer only. It contains no source code.

---

## التثبيت — Install

### بالعربية

1. نزّل أحدث ملف تثبيت من صفحة [**Releases**](../../releases/latest) — اسمه يبدأ بـ `FactoryMarket-Setup`.
2. افتح الملف بالنقر المزدوج.
3. سيظهر تحذير أزرق من ويندوز (**Windows protected your PC**) لأن البرنامج غير موقّع رقمياً بعد.
   اضغط **More info** ثم **Run anyway**.
4. يثبّت البرنامج نفسه ويفتح مباشرة. لا يحتاج صلاحيات المدير، ولا يحتاج إنترنت بعد التثبيت.

يظهر اختصار البرنامج على سطح المكتب وفي قائمة ابدأ باسم **ماركتنگ Factory Market**.

### In English

1. Download the newest installer from the [**Releases**](../../releases/latest) page — the file starting with `FactoryMarket-Setup`.
2. Double-click it.
3. Windows shows a blue **"Windows protected your PC"** notice, because the app is not code-signed yet.
   Click **More info**, then **Run anyway**.
4. It installs itself and opens. No administrator password is needed, and no internet is needed after installing.

A shortcut called **ماركتنگ Factory Market** appears on the desktop and in the Start menu.

## التحديثات — Updates

يتحقق البرنامج من وجود تحديث بنفسه عند التشغيل وكل بضع ساعات، وينزّله في الخلفية.
**لا يُثبَّت التحديث أثناء العمل** — يُطبَّق عند إغلاق البرنامج، فلا تضيع أي فاتورة أو وردية.
وإذا لم يكن هناك إنترنت، لا يحدث شيء ولا تظهر أي رسالة خطأ.

The app checks for updates on its own at launch and every few hours, and downloads them in
the background. **Nothing is ever installed while you are working** — an update is applied
when the app is closed, so no sale and no shift can be lost to it. With no internet, nothing
happens and no error is shown.

## بياناتك — Your data

قاعدة بيانات المتجر ونسخها الاحتياطية محفوظة في مجلد بيانات المستخدم على جهازك:

The shop's database and its backups live in your own user data folder:

```
%APPDATA%\Factory Market\data
```

التحديث لا يمسّها. وإزالة البرنامج **لا تحذفها**.
Updating never touches it. Uninstalling does **not** delete it.
